# Introduction to Network Science — Laboratory Assignments

Practical coursework covering complex network representation, visualisation, statistical analysis, network models, ranking, and community detection using **Python, NetworkX, and Cytoscape**.

## Laboratories

**Lab 01 — Cytoscape Network Visualization**  
Cytoscape graph import, layouts, degree distributions, connected components, cliques, and large network visualization.  
Main file: [`Lab_01_Cytoscape_Network_Visualization_and_Analysis.pdf`](01_Cytoscape_Network_Visualization/Lab_01_Cytoscape_Network_Visualization_and_Analysis.pdf)

**Lab 02 — Flavor Networks and Clustering**  
Bipartite ingredient-compound graphs, ingredient projections, clustering with Cytoscape, and food-pairing networks.  
Main file: [`Lab_02_Bipartite_Flavor_Networks_and_Clustering.ipynb`](02_Flavor_Networks_and_Clustering/Lab_02_Bipartite_Flavor_Networks_and_Clustering.ipynb)

**Lab 03 — Text Based Network Analysis**  
Building directed mention and undirected co-mention graphs from text; connected components, clustering, and degree distributions.  
Main file: [`Lab_03_Mention_and_CoMention_Networks_from_Text.ipynb`](03_Text_Based_Network_Analysis/Lab_03_Mention_and_CoMention_Networks_from_Text.ipynb)

**Lab 04 — Weighted International Trade Networks**  
Weighted directed international trade graphs; exports, imports, trade hubs, and comparisons over time.  
Main file: [`Lab_04_Weighted_Trade_Networks_and_Flow_Analysis.ipynb`](04_Weighted_International_Trade_Networks/Lab_04_Weighted_Trade_Networks_and_Flow_Analysis.ipynb)

**Lab 05 — PageRank and Web Spam**  
PageRank on a web-host graph, degree and ranking comparisons, non-spam PageRank, and spam-gain analysis.  
Main file: [`Lab_05_PageRank_and_Web_Spam_Analysis.ipynb`](05_PageRank_and_Web_Spam/Lab_05_PageRank_and_Web_Spam_Analysis.ipynb)

**Lab 06 — Random Graphs and Preferential Attachment**  
Erdos-Renyi random graphs, connectivity transitions, degree distributions, and Barabasi-Albert preferential attachment.  
Main file: [`Lab_06_Erdos_Renyi_and_Barabasi_Albert_Network_Models.ipynb`](06_Random_Graphs_and_Preferential_Attachment/Lab_06_Erdos_Renyi_and_Barabasi_Albert_Network_Models.ipynb)

**Lab 07 — Connected Components and K Cores**  
Network robustness under edge deletion, connected components, giant components, and k-core decomposition.  
Main file: [`Lab_07_Connected_Components_and_K_Core_Decomposition.ipynb`](07_Connected_Components_and_K_Cores/Lab_07_Connected_Components_and_K_Core_Decomposition.ipynb)

**Lab 08 — Modularity and Community Detection**  
Community structure, graph modularity, edge betweenness, and the Girvan-Newman community detection algorithm.  
Main file: [`Lab_08_Modularity_and_Girvan_Newman_Community_Detection.ipynb`](08_Modularity_and_Community_Detection/Lab_08_Modularity_and_Girvan_Newman_Community_Detection.ipynb)
